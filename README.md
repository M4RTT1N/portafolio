## Proyectos

### Narrativa de datos: transformación digital de TechCorp

Análisis de 18 meses de transformación digital en una empresa de manufactura, con una recomendación de inversión dirigida al CEO. Agrupé 97 registros semanales por trimestre y encontré que todo el avance ocurrió en un solo trimestre, mientras la satisfacción de los empleados caía 12 puntos.

**Herramientas:** Python · pandas · matplotlib
**Entregables:** notebook, cuatro visualizaciones, estructura narrativa, presentación ejecutiva y storyboard

## Por qué uso GitHub como repositorio

Elegí GitHub para alojar mi portafolio por cuatro razones:

- **Renderiza notebooks de Jupyter.** Los archivos `.ipynb` se ven ejecutados en el navegador, con tablas y gráficos. Quien revisa mi trabajo no necesita descargar nada ni instalar Python.
- **Controla versiones.** Guarda el historial de cada proyecto, lo que permite mostrar cómo evolucionó un trabajo y no solo el resultado final.
- **Tiene perfil público.** El README de perfil funciona como carta de presentación, en la misma página donde están los proyectos.
- **Es el estándar del rubro.** Un reclutador del área de datos ya sabe cómo leerlo.

Consideré también YouTube y Stack Overflow. YouTube sirve para difundir un producto terminado, pero no muestra el código ni el proceso. Stack Overflow muestra participación en una comunidad técnica, no proyectos propios.

## Buenas prácticas que aplico

- **Un README por proyecto** que explique qué problema resolvía, qué hice y qué resultado obtuve.
- **Pocos proyectos y buenos.** Prefiero cuatro trabajos documentados que quince ejercicios sueltos.
- **Los gráficos van en el README**, visibles sin descargar nada.
- **Estructura ordenada y consistente:** datos, notebook, gráficos y documentos, con los mismos nombres en todos los proyectos.
- **Documentar el origen de los datos** y la limpieza aplicada.
- **Contacto visible** en el perfil y en cada proyecto.
- **Actualización periódica.** Un portafolio detenido transmite lo contrario de lo que busca.
- **Cuidar la ortografía y la redacción** con el mismo criterio que el código.
